# CLAUDE.md — правила работы над «Винной энциклопедией»

Этот файл Claude читает автоматически при старте. Цель — **тратить как можно меньше токенов на новую страницу региона/AOC**. Читай этот файл и `starter/`, а не готовые страницы.

## Кто пользователь
Денис, новичок в программировании. Отвечает и пишет по-русски. Объясняй шаги простыми словами, без непонятных терминов; код давай целиком с комментариями. Не хвали без нужды, критикуй по делу.

## Золотые правила экономии
1. **Не читай целиком** `content/france/loire/touraine/bourgueil/` и страницу Монтань-Сент-Эмильон (page.yaml ~30 КБ, text.md ~26 КБ). Бери пустой шаблон из `starter/aoc/` — там уже есть все поля и пояснения. Образец смотри только точечно (`grep`/`sed -n`), если нужно уточнить формат одного поля.
2. **Источники от Дениса — в первую очередь.** Он сам присылает ссылки, PDF, cahier des charges (в чат или в `/mnt/project-files/uploads/`). Сначала используй их; веб-поиск — только для того, чего там нет. Каждая открытая страница стоит токенов: не открывай лишнего.
3. **PDF не собираем.** Сборка PDF отключена до готовности остальных страниц (решение 2026-11-17). Не добавляй `auto: true` в `downloads`, не запускай `node tools/make_pdf.js`. Включить позже: `python3 build.py --pdf`.
4. Собирай сайт **один раз в конце** (`python3 build.py`), а не после каждой правки.
5. Две страницы-образца (Бургёй, Цинандали) не переписывай и не «улучшай» заодно — только если Денис просил.

## Как добавить новую AOC (по шагам)
1. Папка: `content/<страна>/<регион>/[<субрегион>/]<aoc>/` (латиницей, строчными, дефисы).
2. Скопируй `starter/aoc/page.yaml` и `starter/aoc/text.md` в неё, заполни `TODO`. Все 14 разделов обязательны; нет данных — пиши «нет надёжных данных», не пропускай. Цифры-заглушки (100, 1000) замени: нули ломают диаграммы.
3. `geo/` внутри папки: `communes-zone.geojson` (коммуны зоны; Франция — из проекта france-geojson, нужные коды INSEE) и `rivers-zone.geojson` (реки). Для стран без границ участков — диаграмма `points_map` (образец: `content/georgia/kakheti/tsinandali/`).
4. Если страницы-родителя ещё нет — создай `page.yaml` хаба (образцы: `content/france/loire/page.yaml`, `content/georgia/kakheti/page.yaml`). У родителя убери эту AOC из списка `planned`. Новую страну см. `README.md`.
5. `python3 build.py` → должно быть «Проверка: замечаний нет». Нужны `pyyaml`, `markdown`, `jinja2` (`pip install pyyaml markdown jinja2`).
6. Коммит, ветка, PR (см. ниже).

## Что где лежит
- `content/…/page.yaml` — цифры, паспорт, история, климат, туризм, словарик, источники, описание диаграмм.
- `content/…/text.md` — тексты 14 разделов: `short, grapes, rules, style, history, geo, craft, vintages, legend, people, compare, food, travel, glossary` (`## Заголовок {#id}`).
- `content/…/geo/` — карты; `content/…/custom.py` — рисунок «ручной работы» (редко).
- `starter/` — пустые шаблоны (не попадают на сайт). `templates/`, `static/`, `lib/`, `build.py` — движок: меняй только если задача про движок.
- `site/` — результат сборки, руками не править. `README.md` — подробности про разметку и новые страны.
- Полный текст шаблона страницы (правила v1.0) лежит в проектных файлах: `template/region-template.md`; читать нужно только при спорных вопросах.

## Правила содержания (кратко)
- У каждой цифры — год и источник (сноска `[N]` = номер в `sources`). Объёмы производства: среднее за 5 лет + последний год.
- После каждой цифры/диаграммы — 2–4 предложения «понятными словами» (`> …`).
- Единицы: площадь — га; производство — гл (+ бутылки 0,75 л: 1 гл = 133) + литры. Цен не показываем. Долю от страны не показываем.
- Легенды и хозяйства: критерий — 2+ авторитетных гида; без рекламы.
- Строки YAML с «двоеточие + пробел» — в кавычки.

## Git и PR
- Работай на ветке, указанной в задаче; в `main` не пушь. `site/` пересобирай и коммить вместе с изменениями контента, но если открыт другой PR, трогающий `site/`, — не пересобирай лишнего, чтобы не плодить конфликты.
- Описание PR — по-русски: что сделано, источники и ограничения, как проверить.
