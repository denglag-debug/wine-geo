# Каркас портала «Винная энциклопедия» — прототип (2026-11-12)

Это рабочий «скелет» сайта. В нём пока одна настоящая страница AOC (Бургёй, перенесён из пилота
без потерь: текст совпадает слово в слово) и три страницы-хаба (Франция → Долина Луары → Турень).

## Как посмотреть
Откройте `site/index.html` двойным щелчком. Интернет не нужен: меню, поиск, карты, таблицы — всё работает с диска.

## Как пересобрать после правок
```
cd portal
pip install pyyaml markdown jinja2   # один раз: библиотеки для чтения YAML, Markdown и шаблонов
python3 build.py                     # собирает весь сайт в папку site/ и печатает замечания проверки
node tools/make_pdf.js               # делает «Полный PDF» для страниц AOC (нужны Node.js и Playwright)
```

## Что где лежит

| Папка / файл | Что это | Как часто трогаем |
|---|---|---|
| `content/` | **данные**: одна папка = одна страница | постоянно — так добавляются регионы |
| `content/…/page.yaml` | цифры, паспорт, события истории, туризм, словарик, источники, описание диаграмм | |
| `content/…/text.md` | тексты разделов обычным текстом (Markdown) | |
| `content/…/custom.py` | (необязательно) картинка «ручной работы» только для этой страницы | редко |
| `content/<страна>/geo/` | контуры страны и департаментов для мини-карт | один раз на страну |
| `templates/` | **оформление**: шаблоны HTML (`aoc.html` — AOC, `hub.html` — страна/регион, остальные — разделы меню) | редко: правка меняет все страницы сразу |
| `static/` | стили (`style.css`) и скрипт поиска/сортировки (`site.js`) | редко |
| `lib/` | части генератора: чтение папок (`content.py`), разметка текста (`markup.py`), блоки страницы (`blocks.py`), диаграммы (`charts.py`) | Claude |
| `build.py` | **генератор**: склеивает данные и шаблоны, собирает сквозные разделы, проверяет страницы | Claude |
| `site/` | **результат** — готовый сайт. Руками не править: при сборке он создаётся заново | никогда |

## Как добавить новую AOC
1. Создать папку, например `content/france/loire/touraine/chinon/`.
2. Положить туда `page.yaml` и `text.md` (проще всего — скопировать из Бургёя и заменить содержимое).
3. Убрать «Шинон» из списка `planned` в `content/france/loire/touraine/page.yaml`.
4. `python3 build.py`. Шинон сам появится: в хлебных крошках, в «Рядом» у Бургёя, в списке Турени,
   точкой на картах, строкой в «Статистике», его события — в «Истории», термины — в «Словаре», в поиске.

## Как добавить новую страну (на примере Грузии, 16.11.2026)
1. Папка страны: `content/georgia/page.yaml` (`type: country`) и папка `geo/` с тремя файлами:
   `country.geojson` (контур страны), `regions.geojson` (края/департаменты, у каждого поле `code`),
   `rivers.geojson` (реки, поле `name`). Все карты страны рисует одна функция `country_map`.
2. В `page.yaml` страны — блок `map:` с настройками карты: `bbox` (рамка: долгота от/до, широта от/до),
   `capital` (столица и её координаты), `capital_offset` (сдвиг подписи столицы, если налезает),
   `rivers` (какие реки рисовать), `river_label` (подпись реки). Без блока `map:` страница соберётся, но без карт.
3. Уровней может быть сколько угодно: у Грузии «страна → край → наименование», без субрегиона.
4. Полезные поля для «не-французских» страниц: `kicker` (подпись над названием, например «Наименование места
   происхождения (PDO)»), `passport_title`, `stats.colors_text` (если долей цветов нет), `stats.status`
   (AOC, PDO, DOCG…), в климате — `tiles` (свои плитки, если у метеостанции нет солнца или заморозков).
5. Если точных границ участков нет — диаграмма `type: points_map`: контур края (`geo/region.geojson`),
   реки (`geo/rivers-zone.geojson`) и сёла точками. Образец: `content/georgia/kakheti/tsinandali/page.yaml`.

## Как добавить статью
Положить файл `articles/<имя-латиницей>.md`. Вверху между строками `---` — шапка: `title` (название), `date`,
`summary` (1–2 предложения), `tags` (темы, по ним фильтруется список), `places` (к каким страницам относится, например
`[france/loire]` — тогда статья видна на странице Долины Луары и всех страниц ниже), `sources`. Ниже — текст в той же
разметке, что и text.md. Образец: `articles/bourgueil-vs-saint-nicolas.md`.

## Разделы меню (с 13.11.2026)
- **Регионы** — дерево свёрнуто, раскрывается по щелчку; есть поиск и «развернуть/свернуть всё».
- **История** и **Статистика** — фильтр «Где» (вся энциклопедия / страна / регион / AOC) и поиск по словам.
  Выбранное место сохраняется в адресе (`history.html#france/loire`); со страницы-хаба есть кнопки «История региона» и «Статистика региона».
- **Статьи** — список с фильтром по теме и месту.
- **Туризм** как сквозной раздел убран из меню; раздел «Туризм» на страницах AOC остался.
- Карта на хабах и главной: одна точка на каждый раздел ниже (регион, субрегион) с числом готовых AOC.

## Значки в text.md
| Пишем | Получаем |
|---|---|
| `## Сорта винограда {#grapes}` | раздел страницы; `grapes` — его «имя» для ссылок и проверки |
| `[1]`, `[1, 6]` | сноска на источник №1 (номер = место в списке `sources` в page.yaml) |
| `> текст` | блок «Понятными словами» |
| `~ текст` | мелкое серое примечание |
| `::: cards` … `:::` | карточки в две колонки, каждая начинается с `#### Заголовок` |
| `[[chart:map]]` | диаграмма `map` из page.yaml → `charts` |
| `[[short]]`, `[[timeline]]`, `[[climate]]`, `[[tourism]]`, `[[glossary]]` | готовые блоки из page.yaml |
| `{{ fmt(s.area_ha) }}` | число из page.yaml → `stats`, по-русски («1 400») |

## Ловушка YAML, о которой стоит помнить
Если строка в page.yaml содержит «двоеточие + пробел» (`во Франции: по закону`), YAML решит, что это
«ключ: значение», и текст сломается. Такие строки берём в кавычки `"…"`. Генератор ловит этот случай
в «трёх фактах» и пишет замечание.

## Что проверяет build.py
- у каждой AOC есть все 14 разделов шаблона v1.0 (если данных нет — раздел всё равно нужен, с текстом «нет надёжных данных»);
- сноски не ссылаются на несуществующий источник;
- каждый источник из списка где-то упомянут;
- в `{{ }}` нет опечаток (сборка остановится и покажет, где).
